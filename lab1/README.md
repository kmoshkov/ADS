# Вариант 3. Многочлены


Класс многочленов произвольной степени $f(x)=\sum_{i=0}^{n} a_i x^i$

Сделать тип коэффициентов и параметра многочлена шаблонным параметром. Обеспечить работоспособность шаблонного класса как минимум со следующими типами:

- `int`;
- `float`;
- `double`;
- `std::complex<float>`;
- `std::complex<double>`.

Как минимум, предоставить:

- Конструктор с параметрами: **Максимальная степень многочлена**;
- Конструктор с параметрами: **Вектор значений** при соответствующих степенях;
- оператор `[]` для чтения коэффициента при заданной степени (обеспечить корректное поведение при любой неотрицательной степени);
- метод `set` для установки коэффициента при заданной степени (обеспечить корректное поведение в случае любой неотрицательной степени);
- операторы сложения и вычитания многочленов;
- оператор умножения многочлена на скаляр (обеспечить коммутативность);
- вычисление значения многочлена при указанном значении х.
- Метод `shrink_to_fit`, уменьшающий размер многочлена до минимально возможного при наличии ведущих нулей
- Метод `expand`, резервирующих память под более высокие степени с коэффициентом 0.

---

**Задачи:**

Найти координаты (x, y) точки локального экстремума для многочлена степени 2.
